# Security Policy

## Supported versions

| Version | Supported |
|---------|-----------|
| main    | ✅        |

## Reporting a vulnerability

If you discover a security issue in CareOps AI, please report it responsibly:

1. **Do not** open a public GitHub issue for security vulnerabilities
2. Email **shubhangini.9654@gmail.com** with a description and reproduction steps
3. Allow up to 72 hours for an initial response

## Scope

CareOps AI is an operational planning prototype using synthetic, de-identified hospital data. It is **not** a clinical system and must not be used with real PHI without a full security review.
